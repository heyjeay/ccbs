claude code better status

Your Claude Code limits, at a glance.

Never get blindsided by a usage limit again. Watch your 5-hour and weekly limits live, get a heads-up before you run out, and see exactly where every token went. All without leaving your terminal.

⁰install
$ curl -fsSL https://heyjeay.github.io/ccbs/install.sh | sh

then run ccbs setup once, and ccbs  ·  no sudo, checksum-verified

Free & open source. macOS, Linux and Windows. Reads the logs Claude Code already writes, so there's nothing to set up.

ccbs --theme

$ ccbs --features

Everything you want from /usage, and more. Live, in one glance, without leaving the terminal.

¹5h window

A braille graph of your token burn across the current five hours, with % used and a countdown to the reset.

pace tells you whether you'll hit the limit before it resets, and roughly when.

²weekly

Your weekly limit (and per-model ones like Sonnet), when it resets, and a bar for every day of the last week.

³now

Every session that's running: project, branch, model, your latest prompt, and the last thing Claude did, like Bash go test ./...

⁴history

A process-list of every session you've had, with how long it ran and the tokens and cost it took. Sort it, scroll it, open one up.

⁵themes

All 42 btop themes built in. Press t to flip through them, and ccbs remembers your pick.

⁶fits anywhere

A full grid on a wide screen; stacked panels on a phone over SSH or a narrow tmux split. One small binary, no runtime.

where the numbers come from

Your sessions come from the logs Claude Code already keeps on your computer, in ~/.claude/projects. ccbs only reads them, and they never leave your machine.

Your 5-hour and weekly % come from Claude Code itself. Run ccbs setup once and Claude Code passes them to ccbs through its status line on every reply. ccbs makes no requests for them, so there are no rate limits and no logins involved. If you already use a status line, it keeps showing; ccbs setup --remove undoes it.

Without setup, ccbs asks Anthropic directly (the same place /usage looks), signed in with your Claude Code login, which it only ever sends to api.anthropic.com. ccbs --offline never contacts anyone.

Cost is what those tokens would cost at standard API prices, a way to see how heavy a session was. It isn't what your subscription charges you.

No accounts, no analytics, no servers of our own. This website doesn't track you either.
